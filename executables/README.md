# Smart Rename Executables

This folder contains standalone executable releases of Smart Rename.

## Available Versions

### [SmartRename_v1.1.0.exe](SmartRename_v1.1.0.exe) - Latest (June 8, 2026)
**Size:** ~10.3 MB

**New Features:**
- Interactive folder selection at startup
- Folder/subfolder renaming support
- Better iteration support with automatic file list refresh
- Case-only rename support for Windows
- Fixed rename chains and collision detection

**Download & Use:**
1. Download `SmartRename_v1.1.0.exe`
2. Place it anywhere on your computer
3. Double-click to run
4. Enter folder path or press Enter for current directory
5. On first run, enter your free Groq API key

### [SmartRename_v1.0.0.exe](SmartRename_v1.0.0.exe) - Initial Release (May 1, 2026)
**Size:** ~10.3 MB

**Features:**
- AI-powered file renaming with natural language
- Preview mode with collision detection
- Backup logs for safety
- Interactive conversations with AI

## System Requirements

- Windows 7 or later
- Internet connection (for AI API)
- No Python installation required

## Getting API Key

1. Visit [Groq Console](https://console.groq.com)
2. Sign up for free
3. Create an API key
4. Enter it when prompted (first run only)

## Notes

- Your API key is saved in `~/.smartrename/config.json`
- Executables are portable - no installation needed
- Each executable is fully standalone
